# AQ Alta Qualidade

Primeira versão visual do e-commerce AQ Alta Qualidade.

## Publicação na Cloudflare Pages
Projeto estático, sem etapa de build:
- Framework preset: None
- Build command: deixar vazio
- Build output directory: `/`
- Root directory: `/`

## Arquivos
- `index.html`: estrutura da loja
- `styles.css`: identidade visual e responsividade
- `app.js`: catálogo demonstrativo, busca, favoritos e sacola local

## Limites desta versão
Esta é uma demonstração de interface. Produtos, imagens, preços e categorias são ilustrativos e não representam o catálogo oficial. Carrinho e favoritos funcionam somente no navegador e não persistem entre dispositivos. Ainda não há autenticação, pedidos persistentes, estoque real, cálculo de frete, gateway de pagamento ou painel administrativo funcional. Não utilizar para receber compras reais.
